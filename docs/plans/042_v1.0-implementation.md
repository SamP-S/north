# 042 — North v1.0 Implementation Plan


## Context

041 identified 16 bugs (9 empirically confirmed), a set of structural refactors,
and agent/TUI/skill gaps blocking a public v1.0. All design decisions are settled:
freeform status *and* state moves, one `task state` command replacing
promote/demote/archive/restore, bare-number IDs replacing `task-<n>` everywhere,
frontmatter round-tripping done properly, go-git replaced by exec-git, nested-init
refusal, GPL-3.0 (deferred to release step), JSON error output. Out of scope:
CI/goreleaser/LICENSE (publish-time follow-up), batch IDs, `task next`, priority,
board export, everything in `docs/design/99_roadmap.md`.

There is no installed base — **no back-compat shims anywhere**; formats change
outright. The in-repo dogfood board `north/` must be migrated by hand as part of
this work (rename files, strip `task-` from ids/depends_on).

## Scope summary

1. **Freeform moves** — status any→any (active-only unchanged); state any→any; one `north task state <id> <state>` command.
2. **Bare-number IDs** — `12` not `task-12`: ids, filenames (`12-slug.md`), `depends_on`, everywhere.
3. **Bullet-proof file handling** — frontmatter round-trip preserving unknown keys, CRLF tolerance, tolerant listing with warnings, filenames in all errors, atomic writes.
4. **exec-git** replacing go-git (worktree-safe, identity fallback), dependency tree halved.
5. **`north doctor [--fix]`** — duplicates, dangling deps, cycles, unparseable files, CRLF, filename drift.
6. **Agent ergonomics** — `edit --body-file`/`--append-body`, `list --search/--label`, `north config get/set/list`, JSON error output, delete `-y` contract.
7. **TUI** — `s` state picker replacing `p`/`a`, shared modal component, display-width truncation, detail-pane id+deps, `r` refresh, `q` closes help, real-file-format editor, editor abort on non-zero exit, `$VISUAL`/`$EDITOR` fixes.
8. **Skill rewrite** + `north skill check`; design docs + README updated to match.

## Ordered todo

### Phase A — core model & formats (foundation; everything else builds on this)

1. [x] `internal/models/models.go`: delete the `Transitions` graph — replace with
   freeform legality (`IsStatus(target)`, same-status no-op stays); delete
   `StateTransitions` — any valid state ≠ current is legal. Keep `Statuses`,
   `StateOrder`, `StateDirs`, `DefaultStatus` unchanged.
2. [x] Bare-number IDs in `internal/board/board.go`: `NextID` → `"12"`; `idRe` →
   `^(\d+)-`; `TaskFilename` → `<n>-<slug>.md`; `TaskFiles` matches
   `^\d+-.*\.md` instead of `task-` prefix. In `internal/tasks/tasks.go`: `find`
   prefix, `idNum`, `validateDeps` messages; `internal/tui/list.go` `taskIDNum`.
   Frontmatter `id` stays a YAML **string** (quote on write so `id: "12"` never
   becomes an int).
3. [x] New `internal/tasks/frontmatter.go`: parse/serialize via `yaml.Node` so
   **unknown keys and their order round-trip untouched**; typed fields overlay
   onto the node on write. Normalize `\r\n`→`\n` before splitting frontmatter.
   Every parse error includes the filename. Body preserved verbatim except a
   single trailing-newline normalization (drop the current `TrimSpace`).
   `loadTask`/`render` in `tasks.go` rewritten on top of it.
4. [x] Atomic writes in `save()`: write `<target>.tmp` in the same dir, then
   `os.Rename`.

### Phase B — tolerant loading & snapshot

5. [x] New `internal/tasks/snapshot.go`: `Load(boardDir) (*Snapshot, error)` parses
   every task file **once, tolerantly** — malformed files become
   `Snapshot.Warnings []Warning{File, Err}` instead of aborting. Snapshot carries
   tasks (sorted), a by-ID index, and derived counts. Refactor `List`,
   `StatusCounts`, `StateCount`, `Dependents`, and `find`/`Get` to use it
   (mutations still write per-file). Duplicate IDs: snapshot keeps first, adds a
   warning naming both files.
6. [x] Surface warnings: CLI prints `warning: <file>: <err>` lines to **stderr**
   (human/plain) and a `"warnings"` array in `--json` (extend
   `internal/render/render.go` signatures); TUI shows a one-line warning count in
   the status/footer area.

### Phase C — operations & CLI surface

7. [x] `internal/tasks/tasks.go`: `SetStatus` freeform (target must be a valid
   status; task must be active — unchanged); replace
   `Promote`/`Demote`/`Archive`/`Restore` with one
   `SetState(boardDir, id, target)` (valid state, ≠ current); `Cleanup` calls
   `SetState(…, StateArchive)`.
8. [x] `internal/cli/task.go`: replace the four state commands with
   `north task state <id> <draft|active|archive>`; update `move` help text
   (freeform). Delete `stateCmd` helper or repoint it.
9. [x] Delete contract: prompt goes to **stderr**; with `--plain`/`--json` or when
   stdin is not a TTY, refuse without `-y` (`Invalid` error) instead of prompting.
10. [x] `north task edit`: add `--body-file` (reuse `readBody`; `-` reads stdin)
    and `--append-body <text>` (appends with a blank-line separator; mutually
    exclusive with `--body`/`--body-file`). Wire into a new `AppendBody` path or
    an `EditOpts` struct (fold 041 §2.7's options-struct refactor in here).
11. [x] `north task list`: add `--search <substr>` (case-insensitive over
    title+body+labels) and `--label <l>` (exact match, repeatable) filters.
12. [x] New `internal/cli/config.go`: `north config list|get <key>|set <key> <value>`
    — keys: `auto_commit` (bool). `set` validates and rewrites `config.yml` via
    `board.WriteConfig`. `board.LoadConfig` stops silently swallowing malformed
    YAML — return `Invalid` naming the file.
13. [x] JSON errors: in `cli.Execute()`, when the failing command had `--json`
    set, emit `{"error":{"code":"<code>","message":"<msg>"}}` to stderr (exit 1
    unchanged); text `error: <msg>` otherwise. Non-BoardErrors use code
    `"internal"`.
14. [x] `north init`: refuse when a board already exists at or above cwd —
    `error: north already initialised (<path>)`. Same-dir re-init stays
    idempotent-with-message? No — same rule, refuse with the same error.
15. [x] New `internal/tasks/doctor.go` + `internal/cli/doctor.go`:
    `north doctor [--fix] [--plain|--json]`. Checks: unparseable files, duplicate
    IDs, filename↔frontmatter-ID drift, dangling `depends_on`, dependency cycles
    (DFS), CRLF files. `--fix`: renumber duplicates to fresh IDs (updating all
    `depends_on` references), rewrite CRLF→LF, rename drifted filenames;
    unparseable files are reported only. Exit 1 when unfixed issues remain, 0
    when clean.
16. [x] `internal/git/git.go` rewrite: shell out to system `git`
    (`git add -- <paths>` + `git commit -m <msg> -- <paths>`), run from the board's
    repo root; works in linked worktrees. If identity is unset, retry with
    `-c user.name=north -c user.email=north@localhost`. Not-a-repo stays a
    silent skip; missing `git` binary with `auto_commit: true` is a real error.
    Drop `go-git` from `go.mod`, `go mod tidy` (also fixes the stale
    direct/indirect markers). Update `git_test.go` accordingly (exec real git in
    a temp repo, incl. a linked-worktree case and a no-identity case via env).

## Verification

- `make vet && make test` green (includes all new unit tests).
- Scratchpad e2e re-run of every 041-confirmed bug, now expecting the fixed

  duplicate IDs → warning + `doctor` reports (+ `--fix` renumbers);

  `task delete --json` without `-y` → clean JSON error, no prompt on stdout;
  nested `init` refused; unknown frontmatter key survives `edit`+`move`;
  `task state 3 archive` from draft and `move 3 failed` from ready both succeed.
- TUI smoke: run `north tui` against the dogfood board; check `s`/`m` pickers,
  `r`, `q`-on-help, multibyte title rendering, editor create/edit round-trip.

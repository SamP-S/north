# 046 — v1.0 accepted items

Implements the ten items accepted for v1.0 in the roadmap review
(`docs/design/99_roadmap.md`, 2026-07-06/07). Scope is exactly the accepted
list — no deferred/rejected items. Foundations first (lock, version, errors),
then CLI surface, then `init` scaffolding, then docs.

## Files to modify

- `internal/board/` — new `lock.go` (+ test); `board.go` (config `version`
  check).
- `internal/errors/errors.go` — exit-code mapping from typed codes.
- `internal/cli/root.go`, `cmd/north/main.go` — exit-code contract, error
  printing with code, lock acquisition around mutating commands.
- `internal/cli/task.go` — batch ids on move/archive/etc., `--assignee`
  filter, wider `--plain` columns.
- `internal/cli/init.go` — `version: 1`, `task-template.md` scaffold,
  `.gitattributes` scaffold, next-steps epilogue.
- `internal/cli/config.go` — read-only `version` key (list/get show, set
  refuses).
- `internal/tasks/tasks.go` — bodyless create fills from
  `north/task-template.md`.
- `internal/tasks/doctor.go` — warn on missing `.gitattributes`, `--fix`
  restores.
- Docs: `README.md`, `docs/design/*` (03_cli, statuses wording),
  `internal/skill/` SKILL.md (exit codes, template, batching).

## Todo

1. [x] **Advisory file lock** — `internal/board/lock.go`: `north/.lock` via
   `O_CREATE|O_EXCL` (pid+timestamp payload), short retry loop, stale-lock
   steal; taken briefly around every mutating command, released on exit.
   Closes the NextID race. Stdlib only. Unit tests (contention, stale steal).
2. [x] **Format version stamp** — `init` writes `version: 1` to `config.yml`;
   load refuses a newer version ("created by a newer north"); missing key
   treated as v1 is *not* allowed to arise (init always writes it). Read-only
   `version` config key: shows in `config list`/`get`, `set` refuses. No
   migration machinery.
3. [x] **Universal exit-code contract** — map typed error codes to exit codes,
   identical in every output mode: 0 success, 1 internal, 2 invalid/usage,
   3 not_found, 4 conflict. Plain errors print the code
   (`error [not_found]: …`). Wire in `main.go`/`root.go`.
4. [x] **CLI batch ids** — comma-delimited ids on id-taking task commands
   (`north task move 2,3,4 done`; arg shape unchanged): dedup,
   continue-on-error with per-id report; partial failure exits with the shared
   failure code, else 1 (per the contract above).
5. [x] **`--assignee` filter on `task list`** — consistent with
   `--label`/`--status`.
6. [x] **Wider `--plain` task list** — add assignee + labels as tab columns
   (empty when unset).
7. [x] **Default body template** — `init` scaffolds editable
   `north/task-template.md` (Summary / Acceptance Criteria / Notes / Changes /
   Comments); bodyless `create` fills from it; missing/empty file → blank body
   (embedded default is init-scaffold only, never a runtime fallback); never
   parsed back.
8. [x] **`init` scaffolds `north/.gitattributes`** (`* text eol=lf`)
   unconditionally as a board file; doctor warns when missing, `--fix`
   restores.
9. [x] **`init` next-steps epilogue** — human-mode "Optional next steps"
   block: `north skill install`, then `north config set auto_commit true`
   (framed optional, not recommended). Suppressed under `--plain`/`--json`.
10. [x] **Docs hygiene** — reword "freeform" for status/state (free *movement*
    within the fixed set); confirm doctor flags hand-edited unknown statuses;
    document exit codes, batching, template, and new flags in README + skill.
11. [x] **Gate** — `make vet && make test` (Windows paths matter for the lock:
    keep it `os`-portable).
12. [x] **TUI doctor view** (added post-review) — `D` opens a scrollable
    doctor popup (reusing the modal machinery): runs `tasks.Doctor` read-only
    and lists issues ("board is healthy" when clean); `f` inside applies
    `--fix`, re-runs doctor, and reloads the board. Footer warning becomes a
    pointer (`⚠ N file warning(s) — D doctor`); help overlay gets the row.
    Shows the doctor report only (superset of snapshot warnings). Behavioural
    tests; README TUI section + 06_testing updated. Re-run the gate.

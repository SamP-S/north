# 007 — CLI

> **Superseded by [031 — Unified North CLI](031_unified-north-cli.md).** The
> separate `aurora` and `borealis` CLIs described here were replaced by a single
> `north` CLI; the old CLI packages and entry points have been deleted. Retained
> for historical context only.

## Summary

Implement the `aurora` CLI: a thin HTTP client wrapping all service API endpoints. Covers observation commands, runtime control, process lifecycle (systemd), feature review commands, and project management. Plain-text output; no interactive TUI. Depends on all prior stages (service must be running).

## Files to Create / Modify

```
cli/
  __init__.py
  main.py                      # entry point; argparse top-level parser
  client.py                    # HTTP client wrapper (httpx); base URL 127.0.0.1
```
